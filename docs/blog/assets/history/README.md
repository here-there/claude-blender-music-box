# 历史错误图示：齿轮传动没有咬合

供博文回溯使用。错误版本保存在 git 标签 `v0.1-gear-misaligned`，修复后的版本在其后的提交中。

## 现象

用户在页面上拉近机芯时发现：发条盒外圈的大齿圈和滚筒右端的小齿轮之间没有接触，发条的动力“隔空”传到了滚筒上（`before-app-user-report.png`，用户截图，蓝圈处）。

## 原因

Blender 建模脚本中有三处传动问题：

1. **轴向错位**：滚筒小齿轮位于 x 0.0125–0.0152 m，发条盒齿圈位于 x 0.0159–0.0186 m，两者在轴向上相距约 0.7 mm，从未处在同一平面。俯视图 `before-barrel-pinion-top.png` 中可以看到小齿轮整个落在齿圈左侧。
2. **齿数与转速不符**：齿圈 72 齿、小齿轮 12 齿，按齿数应为 6:1，但动画让发条盒以滚筒转速的 1/8 转动，转起来轮齿会相互滑移。两齿轮的半径也不成比例（各自按“齿顶半径”随手取值），即使对齐也无法正确啮合。
3. **调速轮系方向与倍数错误**：滚筒大齿轮 64 齿带动 10 齿传动小齿轮，动画却按 +3 倍转动；外啮合齿轮应当反向，倍数也应由齿数决定。风扇转速 96 倍同样与传动轮 48 齿、单头蜗杆不符（`before-greatwheel-train.png`）。

## 修复

- 每对齿轮共用同一个模数 m，节圆半径 r = m·N/2，两节圆半径之和等于中心距（发条盒对 15.5 mm，传动轮系 14.7 mm）。
- 发条盒齿圈移到与小齿轮相同的轴向位置（x 0.0125–0.0152 m）。
- 齿数与动画转速比统一由同一组常量导出：发条盒 72:12（转速 −1/6），大齿轮 48:16（转速 −3），风扇 = 3 × 48 = 144 倍。
- 按啮合点方向设置初始相位，让小齿轮的齿正对大齿轮的齿槽；数值检查转动过程中最小齿间隙为正（约 0.09 mm 与 0.12 mm），即始终咬合且不穿插。

修复后同机位的渲染为 `after-*.png`（`after-app-closeup.jpg` 是修复后在页面中看到的发条盒与滚筒小齿轮啮合处），可与 `before-*.png` 逐张对比。渲染脚本：`blender/render_closeups.py`。
